# Trumpet Central working instructions

Build a free, independent educational resource for trumpet players at all levels. Read `planning/README.md`, then the documents relevant to the task. Preserve established audience, Markdown sourcing, and editorial decisions across sessions.

- Use `planning/content-tracker.md` as the work queue; update it with actual progress and unresolved issues.
- Follow `planning/editorial-guide.md`. Do not fabricate experience, citations, rights, testing, or human review.
- Keep unreviewed content in `planning/`. The public content source is `docs/`; do not maintain competing published copies.
- Prefer focused lessons with practical outcomes, clear prerequisites, and next steps. Distinguish written and concert pitch.
- Follow `planning/agent-workflow.md` for briefs, drafting, review, and handoff. Roles can be performed sequentially; separate agent processes are optional when requested.
- Preserve existing URLs or implement and verify redirects when moving public pages. Inspect the site configuration before integration.
- Run relevant checks for changed content. Planning-only changes need link/structure checks; website integration needs a production build and rendering review.
- Keep changes reviewable. This planning package does not itself authorize deployment or publication. Follow the user's current task scope; do not ask again for actions already authorized.
- Existing prose is material to audit, not evidence that its advice is correct.

Reusable skills should be extracted after the sample workflow has been evaluated. Do not build a custom agent service just to execute these steps.
