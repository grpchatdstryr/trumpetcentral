# Repeat a note with a steady pulse

Use one familiar note to practice keeping time while you play and while you rest. You do not need to change notes for this activity.

## Before you start

You should already be able to make a comfortable sound and repeat it. If producing a sound is still difficult, work on that with a teacher before adding this task.

You will need a metronome: a device or app that makes evenly spaced clicks. Start at 60 beats per minute, which gives one click each second. This is a suggested starting setting, not a target you must reach.

## Clap the pattern first

Count “1, 2, 3, 4,” saying one number with each click. Clap on 1 and 3. Keep counting on 2 and 4 without clapping. Try two rounds.

If you lose your place, listen to four clicks and start again. You can do this part without the trumpet.

## Play and leave space

Choose a note that already feels easy. Keep the same fingering throughout.

| Count | Action |
| --- | --- |
| 1 | Start the note with the click; sustain it until count 2 |
| 2 | Stop the sound; leave this beat silent |
| 3 | Start the same note; sustain it until count 4 |
| 4 | Stop the sound; leave this beat silent |

Play one round, then lower the trumpet for at least one full round of counting. Breathe normally during the break. Try up to three playing rounds, taking longer breaks if you need them. Stop if playing becomes uncomfortable.

The playing and rest amounts are options for this activity, not a daily endurance prescription.

## What to notice

Listen for two things: do the notes begin with the clicks, and are counts 2 and 4 silent? Keep counting through the rests. Those silent beats are part of the pattern.

You do not need a perfect tone to notice whether the timing is becoming more consistent.

## If the pattern feels rushed

Return to clapping. Then play only on count 1, stopping at count 2 and resting through counts 2, 3, and 4. Try the two-note version again when you can follow the count comfortably.

If starting the sound itself remains difficult, ask a teacher to watch and listen rather than repeating the exercise with more effort.

## Next step

Record one round and listen for the starts and silent beats. Choose just one thing to improve on the next attempt. This is an original practice suggestion; adjust it to your current playing ability.
