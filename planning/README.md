# Trumpet Central planning

Mission: make Trumpet Central a free, independent educational resource where anyone can find a useful next step in learning or improving at trumpet.

This package is a proposed publishing system, not a finished curriculum or a claim that the samples have been tested with students. Planning and samples stay outside the published `docs/` directory.

## Decisions already established

- Audience: beginners through advanced players, including returning players.
- Coverage: classical, jazz, improvisation, ensembles, auditions, and professional preparation.
- Voice: independent educational resource, with no invented personal experience.
- Markdown remains the content source.
- The owner's personal goal is at least 15 minutes of daily practice. This is not a commitment to editorial review time or a recommended workload for every reader.
- Build a complete map, then publish coherent learning paths in releases.
