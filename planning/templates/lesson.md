# Replace with the reader's task

Explain the outcome directly. State the intended reader and any pitch convention needed.

## Before you start

List only actual prerequisites and equipment. Link to existing prerequisite content when preparing publication.

## Try it

1. Give a concrete starting action.
2. Specify the activity, rhythm or timing where relevant, and a manageable amount.
3. Include rest, adaptation, and a way to observe the result.

## What to notice

Describe the useful result in language the reader can assess.

## If it is not working

Offer a bounded adjustment and explain when individual guidance is needed.

## Next step

Link to a real available next lesson, or give a self-contained next action in an unpublished draft.

## Sources and further learning

Include only relevant verified sources. Keep internal review notes in the tracker or ledger, not in reader-facing prose. Adapt headings to the task; remove this instructional text before review.
